## Ce que j'ai appris

- Découper un site d'une page en plusieurs pages et les relier avec des liens.
- Lire un code qui existe déjà pour comprendre ce que fait chaque partie, puis le réutiliser sur les autres pages.
- les balises de base to html  
- Créer des classes en CSS et les réutiliser.
- Utiliser `display: flex` pour placer les éléments.
- Faire un formulaire de contact avec des `label` et des champs.
- Modifier les bordures (`border`) du formulaire et des champs de saisie.
- fais des champs obilgatoire ('required')
- Ajouter une image avec `<img>` et changer sa taille pour l'utiliser comme logo du site.
- Mettre le site en ligne avec Git et GitHub Pages.
- créer une botton de submit de formulaire
